01. 실습 목표·폴더 구조

원본 CSV를 읽기 전용으로 재사용하고, 검색용 파생 문서만 만드는 M5 실습입니다. M2 판정이나 M3 기존 검색 소스는 수정하지 않습니다.

Part A · A1-M5 독립 실습

02. 실습 A · NFC와 공백

01_cleaning_basics.py를 실행합니다. NFC는 유니코드 표현을 표준적으로 합치고, 연속 공백을 하나로 만듭니다. WCAG 2.4.4, aria-label, 좋지 않습니다가 남는지 assert로 확인합니다. NFKC의 호환 문자 변환(① → 1)은 의미 보존에 영향을 줄 수 있습니다.

실행 명령

python 01_cleaning_basics.py
Part A · A1-M5 독립 실습

03. 실습 B · OOV와 2-gram

02_oov_and_units.py를 실행합니다. 등록 어휘 집합을 직접 선언하고 메타정합검증이 OOV인지 확인합니다. 공백 토큰과 겹치는 문자 2-gram 결과를 비교합니다. LLM 토큰 ID는 생성하지 않습니다.

실행 명령

python 02_oov_and_units.py
Part A · A1-M5 독립 실습

04. 실습 C · M2 CSV를 검색 문서로

05_prepare_m2_documents.py 실행 시 applied 7건, --include-proposed 옵션을 붙이면 proposed 1건까지 8건입니다. title/description/reason/limitation만 검색 본문으로 합칩니다. 식별자·출처·상태 및 rule_tree.csv 연결키는 메타데이터에 유지합니다.

검증할 필드: raw_text / clean_text / metadata.rule_id / metadata.status / metadata.node_id / metadata.parent_id / metadata.tree_path / metadata.reference_url / metadata.preprocess_version

실행 명령

python 05_prepare_m2_documents.py
python 05_prepare_m2_documents.py --include-proposed
Part A · A1-M5 독립 실습

05. 선택 · Kiwi 품사와 사전

03_kiwi_pos_optional.py에서 조사·어미·부정 표현이 형태소 분석에서 어떻게 나타나는지 확인하고 명사만 남겼을 때 위험을 관찰합니다. 04_kiwi_dictionary_optional.py에서 메타정합검증 사용자 사전 등록 전후를 비교합니다.

실행 명령

python -m pip install kiwipiepy
python 03_kiwi_pos_optional.py
python 04_kiwi_dictionary_optional.py
Part A · A1-M5 독립 실습

06. 선택 · M3 검색 순위 비교

06_compare_m3_search_optional.py는 별도 문자 2~4 gram TF-IDF 비교용 코드입니다. M3 원본 search_engine.py를 수정하거나 완전 동일 실행을 보장하는 코드는 아닙니다. 원문/정제본 검색 순위와 점수 차이를 관찰하고 개선이라고 단정하지 않습니다.

실행 명령

python -m pip install scikit-learn
python 06_compare_m3_search_optional.py
Part A · A1-M5 독립 실습

07. 테스트·점검·제출

python -m unittest discover -s tests -v 로 테스트를 실행합니다. CSV 해시가 실습 전후 동일해야 하며, 검색 품질은 M4의 고정 정답 질문으로 별도 평가합니다.

실행 명령

python -m unittest discover -s tests -v

```text

   v
[클릭 메뉴 / 질문 입력]
   |
   +--> FAQ 메뉴 일치 ----------> [정적 답변] ---------+
   |
   +--> FAQ 키워드 일치 --------> [정적 답변] ---------+
   |
   +--> 보안/권한 요청 ---------> [담당자 절차 안내] ---+
   |
   +--> 명백한 잡담 ------------> [차단 + 이상치 기록] --+
   |
   +--> 나머지 업무 질문 --------> [LLM API] ------------+
                                                    |
                                                    v
                                             [chatbot_logs]
                                                    |
                                                    v
                                               [SQLite DB]
                                                    |
                             +----------------------+----------------+
                             |                      |                |
                             v                      v                v
                       [효율 분석]             [비용 분석]      [이상치 분석]
                             |                      |                |
                             +----------------------+----------------+
                                                    |
                                                    v
                                           [Streamlit Dashboard]
```

## 시스템 엔지니어가 특히 볼 항목
- API 장애/지연과 오류율
- 토큰 급증과 예산 초과
- DB 파일 손상/잠금/용량
- 로그 수집 누락
- FAQ 버전이 오래되어 잘못된 답변이 나가는 문제
- 인증/권한 우회 가능성
- 개인정보가 질문/로그에 남는 문제
- 외부 LLM 사업자 장애 또는 쿼터 제한

## 실운영 확장
SQLite는 데모용이다. 여러 서버/동시 사용자 환경에서는 PostgreSQL 등 서버형 DB로 교체하고, SSO/RBAC, 중앙 로그, 비밀관리, 알림, 백업/복구 체계를 추가한다.

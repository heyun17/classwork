# 시스템 엔지니어 운영 체크리스트

## 운영 전
- SSO/RBAC 적용 여부 확인
- API Key를 코드/Git에서 분리하고 비밀관리 도구에 저장
- 질문/응답 로그에 개인정보 최소화 및 마스킹 적용
- FAQ/정책 문서의 담당자, 버전, 유효기간 지정
- API 일/월 비용 한도와 알림 기준 설정
- 장애 시 FAQ만 유지하는 fallback 경로 준비
- DB 백업/복구 방법 확인

## 매일/매주 볼 항목
- API 오류율과 응답 지연
- 세션당 평균 토큰
- API 미사용률과 FAQ 적중률
- 해결률과 상담원 전환율
- 특정 부서/카테고리의 재질문 증가
- 비업무/이상치 증가
- 로그 수집 누락 여부

## 장애 발생 시 확인 순서
1. 사용자 전체 문제인지 특정 질문만 문제인지 구분
2. HTTP 상태코드: 401/403/429/5xx 확인
3. API latency/error_count 확인
4. 최근 배포, FAQ/프롬프트 변경 확인
5. DB 연결/잠금/디스크 용량 확인
6. 인증/SSO/권한 서비스 확인
7. 외부 LLM 사업자 상태와 quota 확인
8. 필요하면 LLM 경로를 끄고 FAQ + 담당자 안내로 축소 운영

## 비용 급증 시
1. 세션 수 증가인지 세션당 토큰 증가인지 구분
2. Input과 Output 중 어느 쪽이 증가했는지 확인
3. 특정 카테고리/부서/사용 패턴으로 drill-down
4. FAQ가 LLM으로 잘못 넘어가는 라우팅 실패 확인
5. 시스템 프롬프트/검색 문서가 불필요하게 길어진 변경 확인
6. 재시도 루프나 중복 API 호출 확인

## 프로젝트에서 의도적으로 제외한 것
- 직원 개인 생산성 평가
- 직원 행동 감시
- 챗봇이 직접 보안 권한을 변경하는 기능

이 프로젝트의 목적은 직원 감시가 아니라 서비스 비용, 품질, 장애를 운영 관점에서 개선하는 것입니다.

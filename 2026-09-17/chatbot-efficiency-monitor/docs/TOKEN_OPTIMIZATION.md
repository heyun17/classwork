# 토큰/API 자원 최소화 전략

## 1. API 호출 자체를 없애는 단계가 최우선
1. 클릭형 자주 묻는 질문 메뉴
2. 정확/키워드 FAQ 매칭
3. 보안/권한 요청 즉시 담당자 절차 안내
4. 명백한 잡담성 질문만 사전 차단(심심해·놀자·뭐해 등)
5. 캐시된 동일 질문 재사용
6. 위에서 해결되지 않은 업무 질문만 LLM 호출

## 2. LLM을 호출해야 할 때
- 긴 사내 문서를 통째로 프롬프트에 넣지 말고 관련 문단만 검색해서 전달한다.
- 이전 대화 전체 대신 필요한 정보만 요약한다.
- 응답 길이 상한을 둔다.
- 단순 분류는 작은 모델/규칙으로 처리하고 복잡한 답변만 큰 모델로 보낸다.
- 같은 질문을 무한 재시도하지 않는다.
- 질문에 필요하지 않은 개인정보/로그를 프롬프트에 넣지 않는다.

## 3. 대시보드에서 반드시 볼 비용 지표
- 세션당 평균 input/output token
- 부서/카테고리별 token
- API 미사용률
- FAQ 적중률
- 세션당 비용
- 해결 1건당 비용
- 해결 실패 후 상담원 전환된 세션의 API 비용

## 4. 추가 기능 제안
- FAQ 관리 화면과 유효기간: 오래된 정책 답변 방지
- 지식 문서 버전 기록: 어느 규정을 근거로 답했는지 추적
- 장애 시 fallback: FAQ는 유지하고 LLM 질문만 담당자 안내
- 일/월 비용 한도 알림: 토큰 폭증 조기 발견
- 부서별 RBAC: 필요한 지식만 검색 가능
- PII 마스킹: 사번/전화번호 등 민감정보 로그 최소화

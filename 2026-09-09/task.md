# TASK.md

## 작업 목적

- 현재 PC의 기본 시스템 정보를 조회한다.
- `system_monitor.ps1`을 실행하고 출력 결과를 확인한다.
- 조회 이외의 작업은 하지 않는다.

## 작업 위치

- 작업 폴더: `C:\Users\Admin\Desktop\ai-starter`
- 실행 파일: `system_monitor.ps1`

## 실행 명령

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "C:\ai-starter\system-monitor\system_monitor.ps1"
```

## 작업 순서

1. `C:\ai-starter\system-monitor` 폴더가 존재하는지 확인한다.
2. `system_monitor.ps1` 파일이 존재하는지 확인한다.
3. 지정된 실행 명령으로 스크립트를 실행한다.
4. 화면에 시스템 정보가 출력되는지 확인한다.
5. 실행 결과를 사용자에게 보고한다.

## 작업 제한

- `system_monitor.ps1`을 수정하지 않는다.
- 다른 파일도 수정하지 않는다.
- 파일을 생성하거나 삭제하지 않는다.
- 프로그램이나 패키지를 설치하지 않는다.
- Windows 설정을 변경하지 않는다.
- PowerShell 설정을 변경하지 않는다.
- 레지스트리를 변경하지 않는다.
- 관리자 권한이 필요한 변경 작업을 하지 않는다.
- 사용자 지시 없이 오류를 임의로 수정하지 않는다.

## 오류 발생 시 처리

- 오류가 발생하면 즉시 작업을 중단한다.
- 코드나 파일을 임의로 수정하지 않는다.
- 설정을 변경해서 문제를 우회하지 않는다.
- 오류 메시지를 확인한다.
- 오류가 발생한 단계와 예상 원인을 사용자에게 먼저 보고한다.
- 사용자의 추가 지시를 기다린다.

## 완료 조건

다음 조건을 모두 만족하면 작업 완료로 판단한다.

- `system_monitor.ps1`이 정상 실행되었다.
- 시스템 정보가 화면에 출력되었다.
- 실행 중 오류가 발생하지 않았다.
- 파일을 수정하지 않았다.
- 프로그램을 설치하지 않았다.
- 시스템 및 PowerShell 설정을 변경하지 않았다.
- 실행 결과를 사용자에게 보고했다.

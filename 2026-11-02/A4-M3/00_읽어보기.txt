A4-M3 RAG와 OpenSearch 벡터 검색 — 실습자료

[준비]
1. 이 폴더를 그대로 두고, 이 폴더에서 노트북(A4-M3_실습.ipynb)을 엽니다.
2. .env.example 을 복사해 이름을 .env 로 바꾸고 값을 채웁니다.
   OPENSEARCH_PASSWORD = Dashboards 로그인 admin 비밀번호
   OPENAI_API_KEY      = 18탭 LLM 답변을 만들 때만 (없어도 검색까지는 됩니다)
3. pip install opensearch-py sentence-transformers python-dotenv  (LLM까지 하려면 openai)

개발 기간: 5일

1. 프로젝트 개요

1.1 프로젝트명

중학생 학원 학생 관리 시스템

1.2 프로젝트 목적

중학생 60명을 대상으로 운영되는 소규모 학원에서 학생 정보, 반별 소속, 출결 현황, 월별 수납 현황을 웹 화면에서 통합 관리할 수 있는 시스템을 구축한다. 학생별 기본 정보와 학년·반 정보를 체계적으로 관리하고, 일별 출결 현황과 월별 수납 상태를 신속하게 확인할 수 있도록 한다. 또한 대시보드를 통해 학원의 주요 운영 현황을 한 화면에서 확인할 수 있도록 한다.

1.3 운영 규모

  • 대상: 중학생
  • 전체 학생 수: 60명
  • 반 구성: 중1반 20명 / 중2반 20명 / 중3반 20명
  • 반당 정원: 20명

5. 기능명세서

5.1 대시보드

DASHBOARD-001 운영 현황 조회

기능 설명
관리자가 시스템에 접속하면 학원의 주요 운영 현황을 한 화면에서 확인할 수 있다.

표시 정보

  • 전체 학생 수
  • 학년별 학생 수
  • 오늘 출석 인원
  • 오늘 지각 인원
  • 오늘 결석 인원
  • 이번 달 납부 학생 수
  • 이번 달 미납 학생 수

처리 조건

  • 학생 수는 현재 시스템에 등록된 학생 데이터를 기준으로 계산한다.
  • 출결 현황은 당일 출결 데이터를 기준으로 계산한다.
  • 수납 현황은 현재 월의 수납 데이터를 기준으로 계산한다.

5.2 학생 관리

STUDENT-001 전체 학생 조회

기능 설명
전체 학생 60명의 목록을 조회한다.

표시 정보

  • 학생 ID
  • 이름
  • 학년
  • 소속 반
  • 학교명
  • 학생 상태

처리 조건

  • 기본적으로 전체 학생을 조회한다.
  • 학년 또는 반을 기준으로 조회할 수 있다.

STUDENT-002 학생 상세 조회

기능 설명
학생 한 명을 선택하여 상세 정보를 조회한다.

  • 이름
  • 학년
  • 학교
  • 소속 반
  • 보호자 연락처
  • 최근 출결 기록
  • 현재 월 수납 상태

STUDENT-003 반별 학생 조회

기능 설명
중1반, 중2반, 중3반 중 특정 반을 선택하여 해당 반 학생을 조회한다.

처리 조건

  • 각 반의 정원은 20명이다.
  • 선택한 반에 소속된 학생만 조회 결과에 포함한다.

5.3 출결 관리

ATTENDANCE-001 출결 조회

기능 설명
날짜와 반을 기준으로 학생들의 출결 상태를 조회한다.

출결 상태

  • 출석
  • 지각
  • 결석

조회 정보

  • 날짜
  • 학생명
  • 소속 반
  • 출결 상태
  • 비고

ATTENDANCE-002 출결 기록

기능 설명
학생별 출결 상태를 기록한다.

입력 정보

  • 학생
  • 날짜
  • 출결 상태
  • 비고

검증 조건

  • 출결 상태는 출석, 지각, 결석 중 하나여야 한다.
  • 동일 학생의 동일 날짜 출결이 중복 저장되지 않도록 한다.

5.4 수납 관리

PAYMENT-001 월별 수납 현황 조회

기능 설명
특정 월의 학생별 수강료 납부 상태를 조회한다.

표시 정보

  • 학생명
  • 학년
  • 소속 반
  • 대상 월
  • 수강료
  • 납부 상태
  • 납부일

납부 상태: 납부 / 미납

PAYMENT-002 납부 상태 처리

기능 설명
미납 상태의 학생을 납부 상태로 변경할 수 있다.

처리 내용

  • 납부 상태 변경
  • 실제 납부일 기록

검증 조건

  • 이미 납부된 항목은 중복 납부 처리하지 않는다.
  • 납부 금액은 0보다 큰 값이어야 한다.

12. K3s 확장 단계

K3s는 핵심 애플리케이션 기능과 Docker 기반 실행 환경을 구축한 이후 적용한다. 애플리케이션을 K3s 환경에 배포하여 다음 내용을 확인한다.

  • 컨테이너 기반 애플리케이션 배포
  • Deployment 구성
  • Pod 생성 및 실행 상태 확인
  • Service 구성
  • 서비스 접근 확인
  • 애플리케이션 확장 구조 확인

K3s를 통해 Docker 기반으로 개발한 애플리케이션을 컨테이너 오케스트레이션 환경으로 확장한다.

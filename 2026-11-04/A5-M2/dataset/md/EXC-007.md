# 2026년 9월 주문의 이전 정책 적용

## 개요
이 지침은 2026년 9월에 들어온 주문에 대해 10월부터 바뀐 정책이 아니라 9월 당시의 정책을 적용해야 한다는 예외 규정이다. 카드 환불 기간, VIP 무료배송 기준, 냉장식품 품질 이상 접수 기한이 9월과 10월에 서로 다르다. 최신 정책으로 과거 주문에 답하는 실수를 막기 위한 지침이다.

## 업무 규정
2026-09-01~2026-09-30의 v1은 카드 환불 승인 후 5~7영업일, VIP 기본배송 무료 기준 50000원, 냉장식품 품질 이상 접수 기한 24시간이었다. 2026-10-01부터 v2는 각각 카드 3~5영업일, VIP 기준 30000원, 냉장식품 48시간으로 바뀌었다. 기존 주문에 최신 정책을 소급 적용하지 않는다.

## 처리 절차
1. 질문 속 주문의 주문일을 확인한다.
2. 주문일이 2026-09-01~2026-09-30이면 v1 기준을 적용한다.
3. 주문일이 2026-10-01 이후면 v2 기준을 적용한다.
4. 이미 들어온 주문에 나중에 바뀐 정책을 소급 적용하지 않는다.

## 적용 예시
- 9월 20일에 VIP가 40000원을 주문했다 → v1 VIP 무료배송 기준 50000원에 미달하므로 기본배송비가 무료가 아니다.
- 9월 25일 주문의 카드 환불 기간을 묻는다 → v1 기준으로 승인 후 5~7영업일이다.
- 9월 주문의 냉장식품을 받고 36시간 뒤 신고했다 → v1 접수 기한 24시간을 넘었다.
- 9월 주문에 10월 정책을 적용하는지 묻는다 → 원칙적으로 주문일에 유효했던 v1 정책을 사용한다.

## 확인 항목 및 주의
적용 정책: POL-VER-001, POL-REF-001, POL-MEM-001, POL-RET-002. v1은 만료 상태로 저장하되 과거 주문 질의에 사용한다.

## 자주 혼동하는 경우
- v1 정책은 지금 기준으로는 만료되었지만, 9월 주문에 대해서는 올바른 근거다.
- 같은 질문이라도 주문일이 9월인지 10월인지에 따라 답이 달라진다.
- 환불 처리 기간의 시작은 주문일이 아니라 환불 승인일이다.

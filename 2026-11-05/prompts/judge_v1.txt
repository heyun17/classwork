아래 질문에 대한 모델 답변을 평가하시오.

[질문]
{question}

[정답]
{gold}

[모델 답변]
{answer}

[모델이 참고한 문서]
{context}

다음 기준으로 각 항목을 서로 독립적으로 0 또는 1로 채점한다.

- 정확도 (Correct): 모델 답변의 핵심 내용이 정답과 같으면 1, 다르거나 핵심 답이 틀리면 0
- Faithfulness (근거 충실성): 모델 답변에 포함된 모든 사실이 [모델이 참고한 문서]에서 확인되면 1이다. 질문에서 요구하지 않은 추가 정보라도 참고 문서에 근거가 있으면 faithful은 1이다. 참고 문서에 없는 사실을 지어냈거나 근거 없이 추가했을 때만 0으로 평가한다.
- Answer Relevancy (답변 관련성): 모델 답변이 질문의 핵심에 직접 답하고 있으면 1이다. 추가 정보가 있더라도 질문의 핵심에 제대로 답했다면 1로 평가한다. 질문의 핵심에 답하지 않거나 관계없는 내용만 답하면 0이다.

중요:
- Faithfulness는 "질문에서 요구했는가"가 아니라 "참고 문서에 근거가 있는가"만 판단한다.
- Relevancy는 "질문의 핵심에 답했는가"를 판단한다.
- 세 항목을 서로 혼동하지 않는다.

반드시 아래 형식의 JSON 하나만 출력한다. 설명이나 마크다운 코드블록을 추가하지 않는다.

{{"Correct": 0, "Faithfulness": 0, "Relevancy": 0, "reason": "한 줄 이유"}}

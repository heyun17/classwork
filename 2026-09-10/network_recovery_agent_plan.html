Network Recovery Agent 01
POWERSHELL · NETWORK · AUTOMATION

네트워크를 끊고, 다시 연결하고,
정상 복구까지 확인하는 에이전트

관리자가 반복해서 수행하는 네트워크 재연결 작업을 하나의 흐름으로 자동화한다. 단순히 어댑터를 다시 켜는 것에서 끝나지 않고, 마지막에 실제 통신 가능 여부까지 확인해 결과를 보고한다.
AGENT MISSION

Network Recovery Agent가 활성 네트워크 어댑터를 찾아 일시적으로 연결을 끊고, 10초 후 다시 연결한 뒤 ping으로 네트워크 복구 여부를 확인한다.

WHY 네트워크 장애 대응에서 중요한 것은 “다시 켰다”가 아니라 실제로 통신이 정상화되었는지 확인하는 것이다.

사용할 에이전트

ROLE 01

Detect

현재 상태가 Up인 Wi-Fi 또는 Ethernet 어댑터를 자동으로 찾는다.

ROLE 02

Recover

어댑터를 비활성화하고 10초 대기 후 다시 활성화한다.

ROLE 03

Verify & Report

Test-Connection으로 외부 통신을 확인하고 성공·실패를 보고한다.

자동화 흐름

① Active Adapter→ ② Disconnect→ ③ Wait 10s→ ④ Reconnect→ ⑤ Ping Test→ ⑥ Report

에이전트 책임과 실행 명령

Adapter Check상태 확인
Get-NetAdapter로 현재 연결된 네트워크 어댑터를 확인한다.
Disconnect연결 끊기
Disable-NetAdapter를 사용해 대상 어댑터를 비활성화한다.
Reconnect연결 복구
10초 후 Enable-NetAdapter로 같은 어댑터를 다시 활성화한다.
Connectivity Test통신 확인
Test-Connection 8.8.8.8로 인터넷 통신 가능 여부를 검사한다.
Network Recovery Agent · Expected ResultPOWERSHELL
Network adapter: Wi-Fi Disconnecting network... Waiting for 10 seconds... Reconnecting network... Checking network connection... SUCCESS: Network connection is working.
SAFETY RULE IP 주소, DNS, Gateway, 방화벽, 드라이버 등 다른 네트워크 설정은 변경하지 않는다. 관리자 권한 부족이나 명령 오류가 발생하면 임의로 수정하지 않고 즉시 중단 후 오류를 보고한다.
SUCCESS CONDITION

Network Adapter = Enabled · Ping Test = Success · 최종 상태가 “Network connection is working.”으로 보고되면 작업을 완료한다.

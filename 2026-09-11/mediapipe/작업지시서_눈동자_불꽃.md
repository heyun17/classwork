# 작업지시서: 눈동자 중앙 불꽃 합성

## 1. 작업 목적

`face.png`에서 양쪽 눈동자(홍채)의 위치와 크기를 MediaPipe로 찾는다.
`426833.png`의 불꽃 이미지를 눈동자 중심에 배치하고, 불꽃 크기를 눈동자 크기에 맞춰 줄여 합성한다.

최종 결과 이미지 `face_with_fire.png`를 생성한다.

## 2. 입력 및 출력 파일

입력:

- `face.png`: 얼굴 사진
- `426833.png`: 눈동자 위에 붙일 불꽃 이미지
- `face_landmarker.task`: MediaPipe Face Landmarker 모델 파일

실행 파일:

- `pupil_fire.py`

출력:

- `face_with_fire.png`

## 3. 구현 요구사항

`pupil_fire.py`는 다음 기능을 수행해야 한다.

1. `face.png`와 `426833.png`를 읽는다.
2. MediaPipe Face Landmarker로 얼굴을 검출한다.
3. 홍채 랜드마크로 양쪽 눈동자의 중심을 계산한다.
   - 한쪽 홍채: 랜드마크 `468~472`
   - 다른 쪽 홍채: 랜드마크 `473~477`
4. 홍채 랜드마크의 범위로 눈동자 크기를 계산한다.
5. `426833.png`를 비율을 유지하며 눈동자 크기에 맞춰 축소한다.
6. 불꽃 이미지의 흰색 배경은 투명하게 처리한다.
7. 축소한 불꽃을 양쪽 눈동자 중앙에 각각 합성한다.
8. 이미지 바깥으로 나가는 부분은 안전하게 잘라 처리한다.
9. 결과를 `face_with_fire.png`로 저장한다.
10. 정상 처리 시 검출 및 저장 성공 메시지를 출력한다.

## 7. 오류 처리 원칙

오류가 발생하면 다음 순서를 따른다.

```text
오류 메시지 확인
  ↓
발생 파일과 줄 번호 확인
  ↓
관련 코드만 확인
  ↓
최소 수정
  ↓
재실행 및 결과 확인
```

- 입력 파일이 없으면 다른 파일로 대체하거나 임의로 이름을 바꾸지 않는다.
- 한글 폴더 경로에서 OpenCV `imread`/`imwrite` 오류가 나면 `np.fromfile`+`cv2.imdecode`, `cv2.imencode`+`tofile` 방식으로 관련 입출력만 수정한다. 프로젝트 폴더를 옮기거나 이름을 바꾸지 않는다.
- 얼굴 검출 실패를 즉시 코드 오류로 단정하지 않는다.
- 478개 미만의 랜드마크가 반환되면 MediaPipe API 또는 모델 호환성을 확인한다.
- 오류 발생만으로 전체 코드를 다시 작성하지 않는다.
- 정상 코드를 불필요하게 수정하거나 요청되지 않은 기능을 추가하지 않는다.
- 필요하지 않은 패키지, 가상환경, OS 설정 변경을 추가하지 않는다.

# 작업지시서

## 작업 목적

MediaPipe와 OpenCV를 사용하여 `face.png`에서 얼굴 랜드마크를 검출하고, 랜드마크 점·연결선·번호를 표시한 `face_landmarks.jpg`를 생성한다.

## 실행 파일 및 입력 파일

- 실행 파일: `face_landmark_index.py`
- 입력 이미지: `face.png`
- 출력 이미지: `face_landmarks.jpg`
- MediaPipe 모델: `face_landmarker.task`

## 작업 순서

1. `face_landmark_index.py`, `face.png`, `face_landmarker.task`가 존재하는지 확인한다. 없으면 다른 파일로 대체하지 말고 먼저 보고한다.
2. `py --version`을 확인하고, `py`가 없을 때만 `python --version`을 사용한다.
3. `cv2`와 `mediapipe` import를 확인한다. 이미 설치되어 있으면 재설치하지 않는다.
4. `py face_landmark_index.py`를 실행하고, `py`가 없을 때만 `python face_landmark_index.py`를 사용한다.
5. 얼굴 검출, 랜드마크 추출, 점·Mesh 연결선·번호 표시, `face_landmarks.jpg` 생성 여부를 확인한다.

## 오류 처리 원칙

- 오류 메시지와 파일명·줄 번호를 먼저 확인한다.
- 관련 코드만 최소 수정하고 전체 파일을 불필요하게 재작성하지 않는다.
- 얼굴 검출 실패를 코드 오류로 단정하지 않는다.
- 입력 이미지와 프로젝트 구조를 임의로 변경하지 않는다.
- 요청되지 않은 기능과 패키지를 추가하지 않는다.

## 완료 조건

- 얼굴 랜드마크 검출 성공
- 랜드마크 번호와 Mesh 연결선 표시 성공
- `face_landmarks.jpg` 생성
- 출력 파일이 0바이트가 아님

## 완료 보고

성공 시 실행 파일, 입력 파일, 결과 파일, 검출·표시 성공 여부를 짧게 보고한다. 해결하지 못한 오류가 있으면 성공으로 보고하지 않는다.
